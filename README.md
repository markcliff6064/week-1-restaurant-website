# Savanna Grill Website

Savanna Grill is a responsive restaurant website for a fictional Kenyan restaurant located in Kilimani, Nairobi.

## Pages

* Home
* Menu
* About
* Contact

## Features

* Restaurant hero section
* Featured dishes
* Food menu with prices
* Restaurant story
* Team section
* Contact form
* Google Maps location
* Responsive design
* Gallery and hover effects

## Technologies

* HTML5
* CSS3
* Flexbox
* CSS Grid

## Purpose

This project was created to practice building a complete multi-page responsive website using HTML and CSS.

## Location

42 Ngong Road, Kilimani, Nairobi, Kenya
